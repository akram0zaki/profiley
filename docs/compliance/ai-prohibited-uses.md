# AI Prohibited Uses

Last updated: 2026-05-03

The following uses are prohibited for Profiley's AI features.

- Using recruiter chat or job-fit outputs as the sole basis for a hiring, rejection, compensation, or promotion decision
- Representing Profiley outputs as verified facts without checking the cited or underlying candidate material
- Inferring or acting on special-category data, health status, union membership, religion, ethnicity, sexuality, or other sensitive traits from the profile owner's materials
- Using Profiley to build covert behavioural scoring, blacklist lists, or shadow profiles of candidates
- Uploading documents or prompts that the user has no right to process or disclose
- Attempting prompt injection, policy evasion, harassment, or abuse through public or authenticated AI features

If a use case would materially affect a person's employment opportunities, human review is mandatory.
