# AI Literacy Plan

Last updated: 2026-05-03

This plan is for the current operator and any future admin of Profiley.

## Minimum knowledge before managing AI features

- Read `ai-intended-purpose.md`, `ai-prohibited-uses.md`, `human-oversight.md`, and `ai-risk-register.md`.
- Understand that recruiter-facing outputs are assistive, not hiring decisions.
- Understand where retention, deletion, moderation, and provider logs live in the repo.
- Know how to respond to privacy and AI complaints using the DSAR and incident runbooks.

## Review cadence

- Review this set whenever providers or major prompts change.
- Re-review after any AI incident.
- Reconfirm the docs before enabling new recruiter-facing AI capabilities.
