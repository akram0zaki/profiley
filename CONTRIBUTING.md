# Contributing

Unless explicitly stated otherwise, contributions to this repository follow the
same licensing split as the rest of the project:

- Code contributions are submitted under AGPL-3.0-or-later.
- Documentation and other written content contributions are submitted under
  CC BY 4.0.
- No trademark, logo, or branding rights are granted by contributing to this
  repository.

By submitting a contribution, you confirm that you have the right to submit the
work and that it does not knowingly include secrets or material you are not
permitted to contribute.

Before opening a change:

- Keep changes focused and consistent with the existing codebase and docs.
- Follow the workspace instructions in AGENTS.md.
- Do not commit secrets from gitignored env files.
- Preserve or update notices in LICENSE, NOTICE, ATTRIBUTIONS.md, and
  TRADEMARKS.md when your change affects them.

If a change touches branding, screenshots, or other reserved assets, get
written permission before redistributing them.
